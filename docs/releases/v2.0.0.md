# PXSize 2.0.0

Transformez vos images et vidéos en points, pixels, lignes ou chiffres. Choisissez votre effet, ajustez les couleurs, puis exportez votre création. Tout se passe sur votre ordinateur, sans compte.

## Quel fichier choisir ?

| Votre ordinateur | Téléchargement |
| --- | --- |
| **Windows 10 / 11**, PC 64 bits Intel ou AMD | [Installer pour Windows](https://github.com/louiswallet1993-crypto/Pxsize/releases/download/v2.0.0/PXSize-2.0.0-Windows-Setup.exe) |
| **Mac Apple Silicon** — puce M1, M2, M3… | [Télécharger pour Mac Apple Silicon](https://github.com/louiswallet1993-crypto/Pxsize/releases/download/v2.0.0/PXSize-2.0.0-macOS-arm64.dmg) |

| **Linux**, PC 64 bits Intel ou AMD | [Télécharger l'AppImage](https://github.com/louiswallet1993-crypto/Pxsize/releases/download/v2.0.0/PXSize-2.0.0-Linux-x64.AppImage) |

Sur Mac, le menu Apple → **À propos de ce Mac** indique le processeur. Une archive Linux `.tar.gz` est aussi disponible pour les utilisateurs qui préfèrent décompresser l'application.

**Les fichiers « Source code » ne servent pas à installer PXSize.** Le fichier `SHA256SUMS.txt` permet de vérifier les téléchargements ; vous n'avez pas besoin de l'ouvrir pour utiliser l'application.

## Pour commencer

1. Installez et ouvrez PXSize.
2. Glissez une image ou une vidéo dans la fenêtre.
3. Choisissez un effet et cliquez sur **EXPORT**.

[Consulter le guide d'installation](https://github.com/louiswallet1993-crypto/Pxsize/blob/v2.0.0/docs/INSTALLATION.md)

## Ce que vous pouvez faire

- Explorer **8 effets** : trames de points, pixels, lignes déformées et chiffres.
- Travailler en noir et blanc ou créer votre propre palette de couleurs.
- Voir le résultat dans l'application, zoomer et choisir un thème clair ou sombre.
- Exporter vos images en **PNG**, avec leur taille d'origine et une option de transparence.
- Exporter vos vidéos en **MP4**.

## À savoir avant de télécharger

- L'application n'est **pas signée** sous Windows et n'est **pas notariée** par Apple : votre système peut demander une autorisation ou bloquer l'ouverture. Vérifiez la provenance du fichier et consultez le guide ; ne désactivez pas les protections du système.
- L'export vidéo se fait **sans le son d'origine**, à 30 images par seconde, avec une largeur maximale de 1 100 pixels. Les vidéos longues peuvent prendre du temps à traiter.
- Certains MOV ou AVI peuvent ne pas s'ouvrir selon leur encodage. Un MP4 H.264 est le choix le plus simple.
- Les tests automatiques vérifient le lancement, les effets et les exports de l'application empaquetée sur chaque cible. Ils ne remplacent pas une installation manuelle sur toutes les versions de Windows, macOS et Linux.
