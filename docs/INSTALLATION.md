# Installer PXSize

Téléchargez toujours l'application depuis la [page officielle des versions](https://github.com/louiswallet1993-crypto/Pxsize/releases/latest).

## Windows

1. Téléchargez le fichier qui se termine par **`Windows-Setup.exe`**.
2. Ouvrez-le, puis suivez l'assistant d'installation.
3. Lancez **PXSize** depuis le menu Démarrer.

Cette version est prévue pour Windows 10 et 11 sur un PC 64 bits Intel ou AMD. Windows sur ARM n'est pas une cible testée.

**Si Windows affiche une alerte :** le fichier n'est pas signé avec un certificat d'éditeur. Cela ne prouve ni qu'il est dangereux, ni qu'il est sûr. Vérifiez que vous l'avez téléchargé depuis le dépôt ci-dessus. Si vous faites confiance à cette source et que Windows propose « Informations complémentaires », puis « Exécuter quand même », vous pouvez choisir d'autoriser ce fichier. Ne désactivez pas votre antivirus ou SmartScreen. Sur un ordinateur d'entreprise, demandez l'accord du service informatique.

## Mac

1. Dans le menu Apple, ouvrez **À propos de ce Mac**.
2. Si vous voyez **Puce Apple M…**, prenez le fichier **`macOS-arm64.dmg`**. Si vous voyez **Intel**, prenez **`macOS-x64.dmg`**.
3. Ouvrez le fichier `.dmg`, puis glissez **PXSize** dans **Applications**.
4. Ouvrez PXSize depuis ce dossier.

**Si macOS bloque l'ouverture :** l'application n'est pas signée par un développeur Apple identifié et n'est pas notariée. Après avoir vérifié sa provenance, consultez **Réglages Système → Confidentialité et sécurité** pour les options proposées par macOS. Si aucune autorisation n'est proposée, signalez le blocage : ne désactivez pas Gatekeeper et n'exécutez pas de commande de contournement.

## Linux

1. Téléchargez le fichier **`Linux-x64.AppImage`**.
2. Dans ses propriétés, autorisez son exécution comme programme.
3. Ouvrez-le pour lancer PXSize.

L'AppImage vise les distributions de bureau 64 bits Intel / AMD. Selon votre distribution, un composant appelé **FUSE** peut être nécessaire. Suivez alors les instructions de votre distribution. Une archive `.tar.gz` est également proposée pour les personnes qui préfèrent un dossier à décompresser ; lancez l'exécutable `pxsize` à l'intérieur. Ne désactivez pas le bac à sable pour résoudre un problème de démarrage.

## Mettre à jour

PXSize ne se met pas à jour automatiquement. Fermez l'application, téléchargez la nouvelle version depuis la même page, puis remplacez ou réinstallez l'ancienne. Vos images et vidéos exportées restent dans le dossier que vous avez choisi.
